战斗 / Combat

every number in one file

所有数值集中在 src/core/balance.gd，1 格 = 16 px = 1 米，每个距离都带 m/s 换算注释，方便心算校验。

01

近战 MELEE

22 伤害，24 px 触及，±0.95 弧度扇形。总动作 0.38 s，冷却 0.55 s，附带 150 击退。顿帧 0.075 s 让每一次命中都咬得住。

02

手枪 GUN

12 伤害，弹速 320 px/s，12 发弹匣，换弹 1.4 s，每发扩 3°。必须先拔枪才能开火 —— 收枪跑图，拔枪交火。

03

抓钩 HOOK

1200 px/s² 拉力，松手保留 62% 冲量。同一个键既是越障、又是脱身、又是贴脸，是这套移动系统的动词。

04

翻滚 ROLL

0.42 s 位移 132 px/s，其中 0.30 s 无敌，冷却 0.90 s。预判对枪时，这一下就是全部的胜负。

05

赛制 MATCH

团队积分 先到 5 分，回合 3 s 倒计时、3.4 s 慢镜。默认死亡不重生：最后一方站着才算赢下回合。

06

地图 MAP

内置 34×34 竞技场（视线可预期），或输入种子生成 56×56 程序化地图。种子在会话内锁存，改一次就自动失效。

联机 / Multiplayer

listen server · no dedicated box

谁开房间谁就是主机和权威。Bot 只在主机上模拟 —— 所以 3 打 2 的对局不用把每个 Bot 的大脑都推给每个客户端。

01

LAN · 局域网

在 server_port − 1 上广播发现主机，再直连 ENet。大厅里点 SCAN LAN，主机会回一句房间码。

02

P2P · 跨网房间码

信令交换公网端点，双方绑同一个 UDP 端口互相拨号，让 ENet 自己的发包去开洞。FAILSAFE

03

RELAY · WebSocket 兜底

打洞不通时使用：对称型 NAT、运营商级 NAT、公司代理。房间表会镜像进 KV，断线重连仍找得到人。

项 / Item说明 / Detail
房间码 / room code小写字母数字，8 位以内，跨网加入时输入的那串字
人数 / roster2–8 人可配，默认 3 真人 + 2 Bot
权威 / authority仅 Host 跑 AI；客户端的改名与队伍由主机裁定
降级 / fallback信令不可达自动转中继；两端地址都可在设置里改
自建 / self-hostserver/api.php 信令 + server/relay.node.js 中继，两个文件即可部署

下载 / Download说明 / Docs

没有单人难度选项。Bot 只有一档，且不可调 —— 这不是没做完，是设计如此。

没有专用服务器。房间随着主机下线而消失（Listen Server）。想要常驻的房间，得自建 server/api.php 并让主机一直在。

打洞不一定成功。对称型 NAT 会直接落到 WebSocket 中继，延迟更高但一定连得上 —— 走哪条不需要你判断，客户端自己决定。

美术和音效是构建期生成的。精灵、瓦片、音效都来自代码里的程序化图集，所以整个游戏是一个文件，而不是一堆贴图目录。
